# Fiesta Cleaning — Frontend

Next.js App Router application for the Fiesta Cleaning website.

All frontend application code and dependencies live in this `client/` directory.

## Stack

- Next.js 15 (App Router, `src/` directory)
- TypeScript (strict mode)
- Tailwind CSS 4
- GSAP + ScrollTrigger
- Motion
- Lenis
- Lucide React

## Scripts

```bash
npm install
npm run dev
npm run build
npm run start
npm run lint
npm run typecheck
```

The development server runs at `http://localhost:3000`.

Design requirements live in the repository root: [`../FIESTA_PROJECT_MASTER.md`](../FIESTA_PROJECT_MASTER.md).
